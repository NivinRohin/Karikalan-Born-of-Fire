## 2025-02-20 - Reduce GC pressure and memory overhead in high-frequency React Three Fiber components
**Learning:** In high-frequency hooks like `useFrame` (@react-three/fiber), traditional `for` loops should be preferred over array methods like `.forEach()` to eliminate per-frame closure allocations and reduce garbage collection pressure. Additionally, pre-allocating Three.js objects like geometries and materials outside of the component or render loop, and setting `dispose={null}` on the mesh, prevents React Three Fiber from automatically disposing of shared objects, thus preventing memory overhead.
**Action:** When implementing or reviewing components that update per frame (e.g., using `useFrame`), always verify that standard `for` loops are used for iteration over children or arrays, and that any reusable Three.js objects are instantiated outside the loop and shared using `dispose={null}`.
