## 2023-10-27 - [Reduce GC pressure in useFrame loops]
**Learning:** React Three Fiber's `useFrame` runs up to 60 or 120 times per second. Using `.forEach` (which creates closure functions internally or leads to extra allocations) inside this high-frequency loop can create substantial garbage collection pressure. Pre-allocating geometries and materials, and reusing them by passing them as props to the mesh avoids unnecessary object creation on every render. To prevent React Three Fiber from disposing of these reused/shared resources automatically, we must use `dispose={null}`.
**Action:** Always prefer traditional `for` loops in `useFrame` or other high-frequency rendering loops over `.forEach` or `.map`. When pre-allocating geometries and materials, ensure they are instantiated outside of the React component lifecycle and shared across instances with `dispose={null}`.
