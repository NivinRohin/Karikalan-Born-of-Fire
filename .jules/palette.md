## 2024-05-10 - React Three Fiber Canvas Accessibility
**Learning:** By default, R3F `<Canvas>` elements render without accessible semantics and are ignored by screen readers and keyboard navigation. Passing accessibility props (`aria-label`, `tabIndex`, `className`) to `<Canvas>` applies them correctly to the wrapper `div` element rather than the internal `<canvas>` element. When using utility classes like `focus-visible:ring-*` on a full-viewport canvas, `ring-inset` is necessary to ensure the focus indicator renders within the screen bounds.
**Action:** Always add `aria-label`, `tabIndex={0}`, and appropriate `focus-visible` styling (including `ring-inset` for full-screen canvases) when implementing 3D scenes in React Three Fiber to ensure basic keyboard and screen reader accessibility.
