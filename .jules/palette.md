## 2024-05-08 - Accessible Semantics and Keyboard Focus on React Three Fiber Canvas
**Learning:** React Three Fiber's `<Canvas>` component renders as a container with a child `<canvas>` element but lacks accessible semantics by default. Providing `aria-label` and `tabIndex={0}` to the `<Canvas>` allows screen readers and keyboard users to access the 3D scene. Focus events occur on the wrapper `div` rather than the canvas itself, so styling must be applied directly to the `<Canvas>` via `className`, using focus-visible rings to visually indicate focus.
**Action:** When adding an R3F `<Canvas>`, always add `aria-label`, `tabIndex={0}`, and proper focus ring styling (e.g., `focus-visible:ring-4 focus-visible:ring-inset`) to ensure keyboard accessibility and correct focus visibility.
