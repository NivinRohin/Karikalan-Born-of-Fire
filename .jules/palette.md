## 2024-05-05 - Accessible React Three Fiber Canvas
**Learning:** In React Three Fiber, `<Canvas>` elements render without accessible semantics by default, effectively hiding the 3D scene from screen readers and keyboard users. Because R3F injects the `tabIndex` and `aria-label` props onto the wrapper `div` rather than the `<canvas>` element itself, we must apply focus styling (like Tailwind's `focus-visible:ring-*`) to the `className` prop to ensure keyboard navigators can see when the scene has focus. For full-viewport scenes, using an `inset` ring is necessary so the ring isn't clipped off-screen.
**Action:** Always add `aria-label`, `tabIndex={0}`, and `className="focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-inset"` (or equivalent focus rings) to the `<Canvas>` wrapper when creating interactive 3D scenes.
