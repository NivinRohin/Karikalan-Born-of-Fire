## 2026-05-22 - Make React Three Fiber Canvas Keyboard Accessible
**Learning:** React Three Fiber `<Canvas>` elements render as an empty `div` wrapping a `<canvas>` element without any accessible semantics, ARIA roles, or labels by default. Furthermore, R3F attaches keyboard accessibility properties (like `tabIndex`, `aria-label`, and `className` for focus outlines) to the wrapping `div` instead of the internal `<canvas>` element. When adding a focus ring utility class (like `focus-visible:ring-*`), it must be applied with an `inset` style (e.g., `ring-inset`) if the Canvas occupies the full viewport to prevent the focus ring from rendering off-screen.
**Action:** Always explicitly pass `aria-label`, `tabIndex={0}`, and `className="... focus-visible:ring-inset ..."` to R3F `<Canvas>` components to ensure the 3D scene is discoverable by screen readers and navigable via keyboard, making sure focus styling accounts for full-viewport bounds.
