## 2026-05-25 - React Three Fiber Canvas Accessibility
**Learning:** React Three Fiber `<Canvas>` components render without accessible semantics by default. Because keyboard focus is applied to the wrapping `div`, focus styling must be explicitly applied using utility classes (e.g., Tailwind `focus-visible:ring-*`) via the `className` prop. Additionally, full-viewport canvases need `ring-inset` (or equivalent) to prevent the focus ring from rendering off-screen.
**Action:** When creating R3F `<Canvas>` elements, always pass `aria-label` and `tabIndex={0}`. Apply focus styles (e.g., `className="focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-inset focus-visible:ring-white"`) directly to the Canvas to ensure keyboard accessibility and visual indicators are visible.
