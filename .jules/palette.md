## 2025-05-12 - Make React Three Fiber Canvas Keyboard Accessible
**Learning:** React Three Fiber's `<Canvas>` components render an inner `<canvas>` within an outer wrapper `div`. By default, this setup has no accessible semantics or keyboard focusability, essentially hiding the 3D scene from keyboard navigation and assistive technologies. Furthermore, focus styling must be applied specifically (using `ring-inset` for full-viewport canvases) to ensure the focus ring doesn't render off-screen.
**Action:** When adding or auditing a React Three Fiber `<Canvas>`, always inject `aria-label` and `tabIndex={0}` to provide semantics and focus capability, and apply explicit focus visibility styling (e.g., `className="focus-visible:ring-4 focus-visible:ring-white focus-visible:ring-inset outline-none"`) to ensure keyboard users receive clear visual feedback.
